# sheetsift

큰 표(xlsx·csv)를 빠르게 열어 **정렬·필터로 조회하는 읽기 전용 도구**의 바탕.

xlsx 는 zip 안의 XML 이라 바로 읽어서는 빠르게 조회할 수 없다. 한 번 SQLite 로
바꿔 두고, 반복되는 글자는 사전(dict)으로 눌러 담아 정렬·필터를 정수 비교로
끝낸다.

## 상자

| 상자 | 하는 일 |
|---|---|
| `crates/core` | 표 바꾸기(`sheet`), 생김새 알아보기(`infer`), 담는 형식(`sift`), 조회 엔진(`grid`), 비밀번호 봉투(`vault`), 서명한 그릇(`seal`) |
| `crates/aead` | AES-256-GCM 한 겹. 개발 빌드에서도 최적화해 돌리려고 따로 둔다 |
| `crates/web` | 바탕을 브라우저에 붙이는 겹. 알맹이는 보통 Rust 고, `wasm_bindgen` 은 한 파일에만 있다 |
| `web/` | 경계가 도는지 보는 한 장짜리 하네스. **제품 화면이 아니다** |

## 쓰지 않는 층은 들이지 않는다

`sift` 와 `infer` 는 **켜야 들어온다.** 기본은 다 켠 것이고, 줄이려는 앱이
골라서 끈다.

```toml
sheetsift-core = { git = "…", rev = "…", default-features = false }
```

코드가 줄어드는 것이 요점이 아니다. **오류 코드가 한 enum 이라서** 그렇다 —
여기 코드를 하나 늘리면 그것을 쓰지 않는 앱까지 사람이 읽을 문구를 한 줄 써야
하고, 그 문구는 영영 화면에 뜰 수 없다. 켜지 않은 층의 코드는 enum 에 아예
없다.

`core` 는 tauri 도 파일 시스템도 모른다. 바이트를 받고 바이트를 돌려준다 —
데스크톱과 웹(wasm)이 같은 코드를 쓰려면 그래야 한다.

## `.sift`

바꿔 둔 것을 파일로 담는 형식이다. 알맹이는 `sheet` 가 만든 SQLite 그대로고,
거기에 **어디서 온 자료인지**(이름·크기·해시)와 열 정보를 한 줄 더 담는다.
사본은 원본이 바뀌면 낡으므로, 다시 열 때 같은 원본에서 나온 것인지를 그
자리에서 알 수 있어야 한다.

**비밀번호 봉투가 기본이다.** 표에는 사람 이름이 들어 있을 수 있고, 담을 때
고르게 하면 아무도 고르지 않는다. 평문으로 담는 길은 따로 있고, 쓰는 쪽이
일부러 불러야 한다.

**열쇠는 여기 없다.** 봉인 대칭키·서명 공개키·매직은 부르는 앱이 넣는다. 이
저장소는 공개되어 있어, 여기 적힌 열쇠는 누구나 아는 열쇠가 된다.

## 시험

```bash
cargo test --workspace
```

여기에 **글자로 보는 관문**이 같이 들어 있다(`crates/core/tests/secrets.rs`).
복호화한 평문과 열쇠가 스스로 지워지는 그릇에 담기는지, 떨어질 때 지우고 찍힐
때 가리는지, 암호 크레이트의 지우개가 컴파일에 남아 있는지를 소스를 읽어서 본다.
돌려 보는 시험으로는 못 보는 자리라 그렇다 — 지우는 줄이 빠져도 결과는 맞고
초록불이 뜬다.

**지키는 대상을 찾지 못하면 통과가 아니라 실패다.** 그리고 그 관문 자신이
아무것도 보지 않게 되는 것도 똑같이 조용하므로, 일부러 어긋낸 소스를 먹여
서는지를 같은 파일에서 본다.

명령을 새로 만들지 않는다. `cargo test --workspace` 하나가 관문이다.

웹에서도 도는지는 **거기서 한 번 돌려 봐야** 안다. 컴파일되는 것과 도는 것은
다르다 — 운영체제가 없어서 부르는 순간 패닉하는 함수가 있다.

```bash
cargo test -p sheetsift-core --target wasm32-unknown-unknown
```

무엇이 되고 무엇이 안 되는지는 `docs/wasm.md` 에 적어 두었다.

생김새를 알아보는 일(`infer`)이 어디까지 되는지는 `docs/infer.md` 에 있다.

## 브라우저에서 열어 보기

```bash
cargo build -p sheetsift-web --target wasm32-unknown-unknown --release
wasm-bindgen --target web --no-typescript --out-dir web/pkg \
  target/wasm32-unknown-unknown/release/sheetsift_web.wasm
cd web && python3 -m http.server 8080
```

파일을 고르면 그 자리에서 SQLite 로 바뀌고, 정렬·값 선택·검색으로 조회한다.
**자료는 브라우저 밖으로 나가지 않는다** — 올리는 곳이 없다.

`web/` 은 **경계가 도는지 보는 하네스**지 제품 화면이 아니다.

굽는 까닭과 안 되는 것은 `docs/web.md` 에 있다.
